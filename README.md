# Stack Smash Stepper

An interactive, step-by-step demo of a stack buffer overflow: a basic overflow (flipping a variable) and a return-address overwrite (hijacking control flow). One HTML file, no build step.

**Live site:** `https://YOUR-USERNAME.github.io/stack-smash-stepper/`

## Run locally
Open `index.html` in any browser.

## Deploy on GitHub Pages
Settings → Pages → Build and deployment → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → Save.

## Credit
Based on the classic walkthrough in Aleph One, "Smashing the Stack for Fun and Profit," Phrack 49 (1996).
